A chat app for the AI agents already on your computer

Gloss runs on Claude Code, Codex, Gemini CLI, Pi and Cursor Agent. It shows their conversations like a proper chat client and adds one thing they lack: select any text in a reply, ask about it, and the answer appears right under that sentence — without derailing the conversation.

Why this exists
Asking “wait, what does this bit mean?” in a normal chat means copy, paste, a new message — and now the conversation is about that one line instead of your actual question. Gloss keeps the question attached to the text it is about. To the agent, nothing changed: it is one more message in the same chat.

How a clarification works

Three steps. The agent sees an ordinary message.

1

Select

Highlight any text in a reply — a sentence, a list item, a word in a heading, a line of code. An Ask about this button appears over the selection.

2

Ask

A small composer opens under that paragraph. Your question is sent to the agent like any other message: the quoted text plus what you asked. Same session, same memory.

3

Read in place

The answer appears under the sentence it is about — collapsible, with follow-ups threaded inside. You can highlight text in that answer and ask again, as deep as you need.

Also in the box

Artifacts

When the agent writes a page, drawing, diagram, document or file, it shows as a card and opens in a side pane — safe preview, versions, save to disk.

Also in the box

Attachments & search

Drop images and text files into a message. Search every conversation at once — clarifications included. Pin and tag the ones that matter.

Also in the box

Export

Save a reply or a whole conversation as Markdown, with each clarification folded in right under the sentence it was asked about.

Supported agents

Bring the agents you already pay for.

Gloss never talks to a model API. Each message runs the agent's own command-line tool in the background, inside a private folder, so nothing shows up in your real projects. Pick the agent and model per conversation.
