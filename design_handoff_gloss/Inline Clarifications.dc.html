1Highlight-to-clarify — three treatments

Context. In chat today, asking about one line of a response means copy → paste → new turn, and the thread loses the distinction between “continue” and “explain that bit”.

Model. A clarification is an ordinary turn. The only UI trick: its answer is rendered under the sentence it’s about, collapsible, with threaded follow-ups; the transcript keeps a one-line stub pointing to it.

Try it. Select any text in a response → Ask about this → type → Enter. Click a mark or a stub to jump / collapse. Replies are mocked.
